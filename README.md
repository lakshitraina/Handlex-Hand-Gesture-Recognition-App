# ✋ Handlex – Hand Gesture Recognition App

> **Control with Gestures. Interact with Intelligence.**  
> Handlex is a real-time hand gesture recognition application that uses computer vision and machine learning to detect and interpret hand movements for interactive control.

## 📱 Overview

**Handlex** enables gesture-based interaction using camera input and real-time detection algorithms.  
The system captures hand movements, processes them using computer vision techniques, and maps them to specific actions.

This project demonstrates:
- Real-time image processing
- Gesture classification using ML
- Camera integration
- Human-computer interaction concepts

---

## ✨ Features

### 📷 Real-Time Hand Detection
- Detects hand landmarks using computer vision
- Tracks finger positions dynamically

### 🤖 Gesture Recognition
- Recognizes predefined gestures
- Maps gestures to specific system actions

### ⚡ Real-Time Processing
- Low-latency detection
- Optimized frame processing

### 🎯 Interactive Controls
- Control applications using gestures
- Touch-free interaction model

## 🚀 How It Works

1. Capture live video feed from camera.
2. Detect hand landmarks using computer vision model.
3. Extract key points from fingers and palm.
4. Classify gesture based on landmark positions.
5. Trigger corresponding action.
